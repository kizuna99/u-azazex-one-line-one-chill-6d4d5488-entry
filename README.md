A tiny Python program (`main.py`) that writes one single-sentence horror line to `/output/entry.txt` for the make.fun "One Line, One Chill" bounty: a voice recorded on the Moon an hour before the narrator landed, begging mission control not to let him back inside. Run it with `python3 main.py` (set `OUTPUT_DIR` to override the output directory); the output is byte-identical on every run and well under the 200-character gate.
